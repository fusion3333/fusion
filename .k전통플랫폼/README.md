# K전통플랫폼

외국인, 특히 서구권 여행객을 대상으로 한국 전통문화·숙박·웰니스 체험을 발견하고 예약할 수 있게 하는 플랫폼 프로젝트입니다.

## 1차 범위
- 지역: 서울특별시 + 경기도
- 핵심 카테고리: 한옥호텔, 한옥스테이, 한옥민박/게스트하우스
- 확장 예정: 한복, 다도, 전통공예, 사찰/명상, 궁중문화, 전통음식, 한방화장품, 한의원/한방 웰니스 체험
- 우선 고객: 영어권/서구권 FIT(개별여행객), 커플, 가족, 프리미엄 문화여행객

## 데이터 원칙
1. **공식 인허가 데이터가 기준(master)**
2. 실제 판매 가능성은 Google/Booking/Tripadvisor/Airbnb/Agoda/NOL 등 소비자 플랫폼으로 보강
3. 평점은 반드시 출처와 리뷰 수를 함께 저장
4. 폐업/휴업/중복 숙소는 분리
5. 주소는 시/구(군)/동까지 정규화
6. 각 숙소마다 영어명, 외국어 응대, 문화체험, 교통, 가격대, 예약채널, 사진권리, 제휴가능성 필드를 추가

## 현재 확인된 공식 근거
- 행정안전부 전국한옥체험업체표준데이터: 전국 지자체 한옥체험업 인허가 정보를 일괄 취합. 2026-02-10 수정, 파일 2,508행. 원본은 LOCALDATA 파일 URL로 연결되며 매일 갱신되고 2일 전 기준으로 현행화된다고 공공데이터포털이 명시.
- 서울시 자료(2023-12 기준): 한옥체험업 등록 249건. 종로구 201, 은평구 27, 성북구 13, 동대문구 5, 중구 1, 강북구 1, 광진구 1. 이 중 당시 한옥스테이 인증 26건.
- 경기데이터드림: `한옥체험업 현황` 데이터셋이 별도 존재하며 데이터 기준일 2026-05-14로 표시됨.

## 주의
현재 GitHub에 저장된 숙소 목록은 **V0 탐색 데이터**입니다. 공식 전체 인허가 CSV를 가져와 서울/경기 행을 필터링한 후, 각 행을 소비자 평점/리뷰와 매칭해야 '전수조사'가 완성됩니다. 검색엔진이나 지도 검색만으로는 폐업·미노출·신규등록 업소를 빠짐없이 잡을 수 없으므로 공식 인허가 DB를 모집단으로 사용합니다.

## 폴더 구조
- `research/` : 근거 조사, 시장/경쟁사/고객 분석
- `data/` : 원천 및 정제 CSV/JSON
- `product/` : 서비스 구조, UX, 예약/결제/파트너 구조
- `worklog/` : 대화에서 결정한 내용과 다음 작업
