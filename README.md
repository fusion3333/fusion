# 우리동네 안전알림 (Neighborhood Safety)

대한민국 공공데이터를 이용해 사용자의 생활권 치안 통계와 지역 인구 지표를 한 화면에서 보여주는 모바일 앱 프로젝트입니다.

## 핵심 기능

- 현재 위치 또는 선택 지역 기준 치안 정보
- 5대 범죄(살인, 강도, 성범죄, 절도, 폭력) 공개 통계
- 경찰서별/지역별 최근 공개 통계 추이
- 외국인 주민 수와 전체 주민 대비 비율
- 데이터 갱신 시 알림
- 출처와 기준 시점 표시

> 중요: 현재 공개된 경찰 공공데이터는 개별 범죄 사건의 실시간 위치/시각을 제공하지 않습니다. 따라서 앱은 공식 공개 통계를 기반으로 하며, "실시간 범죄 발생 알림"이라고 오인하게 만들지 않습니다.

## 데이터 원칙

범죄 통계와 외국인 주민 비율은 서로 독립된 지역 지표로 제공합니다. 외국인 주민 비율을 범죄 위험의 원인 또는 범죄 가능성의 대리변수로 사용하지 않습니다.

## 예정 데이터 소스

1. 경찰청 / 시도경찰청 공공데이터
   - 5대 범죄 발생 및 검거 현황
   - 경기북부경찰청 경찰서별 데이터 등
2. 경찰청 범죄통계
   - 연간 확정 통계
   - 분기별 잠정 통계
3. 행정안전부
   - 지방자치단체 외국인 주민 통계
4. KOSIS Open API
   - 지역 인구 및 보조 통계

## 기술 스택

- Expo + React Native + TypeScript
- Expo Router
- Zustand
- TanStack Query
- 서버 어댑터 계층을 통해 공공 API 키를 앱에 직접 노출하지 않는 구조

## MVP 화면

- 홈: 선택 지역, 안전 현황 요약, 데이터 기준일
- 범죄: 5대 범죄별 발생 건수와 전년 대비 변화
- 지역: 인구, 외국인 주민 수/비율 등 지역 지표
- 출처: 데이터 출처, 갱신 주기, 한계
- 설정: 관심지역 및 알림 설정

## 개발 시작

```bash
npm install
npm run start
```

공공 API 키는 `.env`에 저장하고 GitHub에는 커밋하지 않습니다.

```env
EXPO_PUBLIC_API_BASE_URL=http://localhost:8787
DATA_GO_KR_SERVICE_KEY=
KOSIS_API_KEY=
```
