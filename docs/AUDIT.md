# 코드·데이터·기능 감사

감사일: 2026-08-27

## 수정 완료

1. Expo SDK 57 패키지 버전 정합성 수정
2. 관심지역/알림 설정 AsyncStorage 영속화
3. 외국인주민 API를 JSON으로 가정하던 오류 제거 및 XML 처리
4. 외국인 주민 비율의 총인구 분모를 동일 API에서 추정하던 오류 제거
5. 총인구를 독립 provider로 분리하고 기준시점이 같을 때만 비율 계산
6. 2025 범죄자료 잠정 표시 지원
7. 범죄 원본 미연결 상태를 0건으로 오인하지 않도록 UI 수정
8. CORS 기본 전체허용 제거
9. 서버 환경변수 문서 보완

## 출시 전 P0

- 실제 data.go.kr 응답 샘플로 외국인주민 XML 태그명을 확정하고 fixture 테스트 추가
- 경찰 공식 CSV/XLSX 원본을 자동 변환하는 importer 구현
- 양주경찰서 관할과 양주시 행정구역의 차이를 메타데이터로 명시
- 실제 주민등록 총인구 provider 연결
- `npm install`, `expo-doctor`, `npm run typecheck`, 서버 typecheck를 실제 CI에서 통과
- API timeout/retry/cache/rate-limit 적용

## 제품 P1

- 현재 위치 → reverse geocoding → 지원 행정구역 자동 선택
- 범죄 연도별 추이 그래프
- 전년 대비 증감률
- 인구 10만명당 범죄 발생률(동일 기준연도 인구만 사용)
- 발생/검거 건수와 검거율 구분
- 데이터 최종 갱신일과 원본 링크
- 복수 경찰서 관할 도시(고양·남양주 등) 집계
- 접근성: VoiceOver/TalkBack 라벨, 동적 글꼴, 고대비
- 오프라인 마지막 정상 데이터 + '저장된 데이터' 명확한 배지

## 알림 P1

현재는 알림 권한 UI만 존재한다. 실제 알림을 위해서는 다음이 필요하다.
- Expo push token 등록 API
- 관심지역 구독 저장소
- 공식 데이터 버전/해시 변경 감지 작업
- 중복 알림 방지 idempotency key
- 알림 클릭 시 해당 지역/기간 상세화면 deep link
- 알림 해지 시 서버 토큰/구독 삭제

## 향후 P2

- 지도는 실제 사건 위치가 아니라 경찰서 관할/행정구역 통계 choropleth 형태로 제한
- 범죄 종류 필터
- 여러 관심지역 즐겨찾기
- 전국 시군구 확대
- 데이터 공급자 장애 상태 페이지
- 통계 정의 변경 이력

## 정확성 원칙

- 0과 미수집/미공개를 구분한다.
- 경찰서 관할과 행정구역을 동일시하지 않는다.
- 잠정자료와 확정자료를 구분한다.
- 기준기간이 다른 분자/분모로 비율을 계산하지 않는다.
- 외국인 주민 지표를 범죄 위험 점수나 인과 추론에 사용하지 않는다.
