# 외부 권한이 필요한 마지막 작업

코드와 공개 문서만으로 처리할 수 있는 범위는 구현했다. 아래는 사용자 계정/비밀키/실기기 권한이 필요한 항목이다.

## 현재 확보된 것

- 공공데이터포털 법정동코드 API 활용승인
- 행정안전부 행정동별 주민등록 인구 API 활용승인
- 행정안전부 유형별 지방자치단체 외국인 주민 API 활용승인
- 경기북부경찰청 경찰서별 5대범죄 API 활용승인
- 경기북부경찰청 2025 CSV 원본 확보

## 남은 외부 작업

1. 노출된 공공데이터 인증키 재발급 후 `server/.env`에만 저장
2. 주민등록 인구 API의 실제 응답 샘플/기술명세로 행정기관코드·통계년월 파라미터와 총인구 필드를 최종 확정
3. 외국인 주민 XML 실제 응답 샘플로 지역명·총 외국인 주민 필드를 최종 확정
4. Expo 계정 로그인 후 EAS projectId 생성
5. Apple/Google 개발자 계정으로 서명
6. 사용자 Mac/실기기에서 GPS, 알림, iOS/Android 빌드 최종 검증

## 전국 범죄 데이터의 구조적 제약

전국의 경찰서별 5대범죄가 하나의 통일된 OpenAPI로 제공되는 것은 현재 확인되지 않았다. 경기북부, 서울, 부산 등 시도경찰청별 데이터셋이 별도로 제공된다. 앱은 전국 행정구역 선택을 지원하되, 공식 범죄 provider가 연결된 지역에서만 범죄 수치를 표시해야 한다. 제공되지 않는 지역의 값을 추정하거나 다른 지역 통계를 대입하지 않는다.

## 보안

서비스키, Apple/Google 계정 비밀번호, 인증서 개인키, 푸시 인증정보는 GitHub·채팅·스크린샷에 기록하지 않는다.
