# 데이터 소스 조사

조사일: 2026-08-27

## 경찰 범죄 데이터

### 경찰청 범죄통계
경찰청은 연간 범죄통계와 분기별 범죄통계 자료를 공개한다. 개별 사건의 실시간 위치/시각 스트림과는 다르다.

### 경기북부경찰청 공공데이터
공공데이터포털 검색 결과 경기북부경찰청의 경찰서별 5대 범죄 발생·검거 현황 데이터가 확인된다. 양주 등 경기북부 지역 MVP 검증에 우선 활용할 가치가 있다.

## 외국인 주민 데이터

### 행정안전부 지방자치단체 외국인주민 현황
행정안전부가 지역별 외국인 주민 현황을 공표한다. 지역 단위와 갱신주기를 확인해 앱 표준 행정구역 코드에 매핑한다.

### KOSIS Open API
인구 및 지역 통계를 보완하는 표준 통계 API 후보. API 키와 대상 통계표를 확정한 후 provider를 구현한다.

## 구현 시 주의

- 데이터셋의 공간 단위가 경찰서 관할과 행정구역으로 서로 다를 수 있다.
- 앱에서 두 단위를 동일한 것으로 표현하지 않는다.
- 발생 건수만 비교하면 인구 규모가 큰 지역이 불리하므로 가능하면 인구 10만 명당 발생률도 함께 표시한다.
- 외국인 주민 비율은 지역 인구 구성 정보로만 제공하고 범죄 위험 점수 계산에 사용하지 않는다.
- 공개 통계의 갱신 지연을 화면에 명확히 표시한다.
