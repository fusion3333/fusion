# FAILURE JOURNEY Completion Gate V1

Decision: PUBLIC_SOURCE_DISCOVERY_LOCKED_ATTEMPT_DENOMINATOR_PARTIAL

Public Evidence Readiness: 0.80
Engine-ready: 0.48

## Locked public layer
- failure modeled as stage transition rather than complaint
- complaint vs verified violation separation
- stage-specific booking/payment/mobility failure taxonomy
- success-with-friction and workaround states
- substitution and recovery states
- time/regime sensitivity
- denominator requirement for any failure rate
- joins to SEARCH, BOOK_PAY, MOVE, REAL_SELLABLE_SUPPLY, PAIN_VOC, SATISFACTION and MONEY_FLOW

## Blocking data
- query/result impression/click/book-start denominators
- inventory check and sold-out attempts
- account/identity onboarding failures
- payment authentication/authorization failures by issuer/card/origin
- booking confirmation failures
- route-search to boarding and arrival conversion
- last-mile abandonment/dispatch failure
- activity attendance/no-show/substitution
- refund/support failure outcomes
- traveler-stated reason linked to event logs
- cross-platform substitution and recovery
- expected value per failed attempt

## Public ceiling rationale
Public sources expose failure mechanisms, complaint systems, selected violations and policy changes. They rarely expose all attempts at the same journey stage. Therefore population failure rates cannot be honestly estimated without partner dashboards, Ground interviews or N telemetry.

## Reopen rule
Reopen public source discovery only when a new source provides true attempted-but-failed denominators or a material new failure mechanism. Otherwise proceed to GROUND_INTELLIGENCE.
