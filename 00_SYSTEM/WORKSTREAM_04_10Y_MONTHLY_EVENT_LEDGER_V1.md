# 4번 작업 — 10년×12개월 사건·체제 장부 V1

기준일: 2026-08-28
대상기간: 2015-01 ~ 2026-08 (현재 140개월; 2026년 종료 후 144개월)

## 목적
관광수요 시계열 옆에 외생변수·정책·충격·통계체제 변화를 같은 월축으로 붙여, 단순 상관 설명이 아니라 향후 인과추론·반사실 분석이 가능한 시간 기반을 만든다.

## 핵심 분리
1. **연속형 공변량**: 환율, 실질/명목실효환율, 물가, 유가, 항공공급/운항, 호텔가격 등.
2. **이산 사건**: 비자/K-ETA, 중국 단체관광, 대형행사, 외교충격, 재난, 콘텐츠 흥행 등.
3. **달력 노출**: 출발국 공휴일·연휴·학교방학 등.
4. **체제변화**: 입국/검역/조사방법/센서 정의가 바뀌어 전후 수치의 생성과정이 달라지는 시점.

연속형 공변량을 사건 CSV에 억지로 넣지 않는다. 사건이 없는 월과 자료가 없는 월도 구별한다.

## 사건 원자 스키마
`event_id,event_type,event_subtype,start_date,end_date,effective_from,effective_to,affected_origin,affected_destination,affected_region,affected_journey_stage,expected_direction,mechanism,source,source_type,confidence,causal_status,regime_break,notes`

## causal_status 허용값
- `event_only`: 사건 존재만 확인. 영향 추정 금지.
- `temporal_cooccurrence`: 관광변화와 시간적으로 겹침.
- `association_evidence`: 공식/연구자료에 연관성 근거가 있으나 식별된 인과효과는 아님.
- `quasi_experiment_possible`: 정책 시행일·대조군 등을 이용한 준실험 설계 후보.
- `causal_evidence`: 별도 인과식별 근거가 확보된 경우만 사용.

## 0 / missing 규칙
- `0`: 해당 사건군을 그 월에 관측·검증했고 사건이 없음을 뜻할 때만 허용.
- blank/`MISSING`: 아직 관측하지 않았거나 공개자료가 없거나 검증되지 않음.
- `NOT_PUBLIC`: 존재 가능성은 있으나 공개자료가 없음.
- `NOT_VERIFIED`: 후보는 있으나 공식/신뢰가능 원출처 검증 전.
- `NOT_COMPARABLE`: 정의·빈도가 달라 직접 결합 금지.
- `REGIME_BREAK`: 생성과정/정의가 바뀌어 전후 직접 연결 금지.

## 절대 금지
사건 존재 ≠ 관광 영향. 검색급증 ≠ 관광객 증가. 콘텐츠 흥행 ≠ 방한 증가의 원인. 항공좌석 증가 ≠ 실제 수요 증가. 환율 변화 ≠ 여행선택의 단독원인. 코로나 기간 ≠ 정상시장. 월자료가 없는 분기/연자료를 임의 월분해하지 않는다.

## 월 패널 연결 규칙
- `MONTH_SPINE_2015_2026M08_V1.csv`가 유일한 월 키다.
- 사건은 유효기간과 월의 교집합으로 bridge를 만들되 원자 사건행을 보존한다.
- 같은 사건이 여러 출발국에 영향을 주면 `affected_origin`을 명시하고, ALL과 특정국가를 혼동하지 않는다.
- 정책 발표일과 실제 시행일이 다르면 `start_date`와 `effective_from`을 분리한다.
- 종료일이 불명확하면 빈칸으로 두고 추정하지 않는다.

## 1차 공식소스 우선순위
한국은행 ECOS/BIS → 법무부/K-ETA → 국토교통부 항공통계 → 질병관리/외교부 공식 입국지침 → 문체부/관광공사 → 각 출발국 정부 휴일 캘린더 → 국가통계기관 → 국제기구. 언론/검색/SNS는 공식 원출처를 찾기 위한 후보발견용으로만 사용한다.
