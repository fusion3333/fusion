# 교차계층 6 — 반사실·미실현 수요 V1

상태: 설계 잠금 / 공개근거 부분확보 / 개인수준 전환·대체행동 자료 필요
갱신일: 2026-08-28

## 목적
현재 관측되는 방한객과 실제 거래만으로는 시장을 볼 수 없다. 한국을 알았지만 후보에 넣지 않은 사람, 후보에 넣었지만 탈락시킨 사람, 예약을 시도하다 포기한 사람, 일본·대만·태국 등으로 바꾼 사람, 여행 자체를 취소한 사람까지 포함해 '발생했을 수 있었으나 실현되지 않은 수요'를 구조화한다.

## 핵심 원칙
- 한국에 오지 않음 ≠ 한국에 관심이 없었음
- 일본 방문 ≠ 한국에서 일본으로 대체됨
- 검색하지 않음 ≠ 한국을 몰랐음
- 예약 실패 ≠ 수요 없음
- 여행 취소 ≠ 목적지 거부
- 현재 매출 0 ≠ 잠재가치 0
- 대체효과는 동일한 후보군 또는 인과적으로 방어 가능한 비교설계가 있을 때만 인정한다.

## 기본 상태
전체 잠재시장 → 한국 인지 → 후보편입 → 비교 → 한국 선택의향 → 예약시도 → 결제시도 → 실제 방한

각 단계에서 다음 이탈상태를 별도 기록한다.
- 비인지
- 후보 미편입
- 후보에서 탈락
- 경쟁국 선택
- 여행 연기
- 여행 자체 취소
- 예약 포기
- 결제 포기
- 이동/비자/시간/예산 제약으로 포기
- 다른 상품·지역으로 대체

## 필요한 객체
### 선택기회
누가, 언제, 어떤 목적지들을 실제 후보로 검토했는지 저장한다.

### 미실현수요사건
- 여행자/의사결정단위
- 단계
- 원래 의도
- 실패 또는 탈락 이유
- 대체 목적지/상품
- 여행 연기 여부
- 무여행 여부
- 당시 가격·항공·비자·시간·예산·공급상태
- 관측시점
- 출처
- 신뢰도

### 대체관계
한국과 경쟁 목적지·상품 사이에서 실제 전환이 있었는지 기록한다. 단순 시장점유율 변화만으로 직접 대체관계를 만들지 않는다.

## 연구근거
관광 목적지 선택 연구는 잠재여행자가 초기 후보집합을 만들고 이를 후기 후보집합으로 줄여 최종 선택하는 단계적 구조를 오래전부터 제시해 왔다. 따라서 최종 방문자만 보면 후보에서 탈락한 수요를 잃는다.

국제관광 수요 연구에서는 경쟁 목적지의 가격을 대체가격으로 포함할 때 관광수요 설명력이 개선되며, 대체효과의 크기는 출발국과 이동수단 등에 따라 달라질 수 있음이 확인됐다. 이는 '한국과 일본은 언제나 완전대체재' 같은 단순 가정을 금지해야 한다는 근거다.

## 반사실 질문
각 기회마다 다음을 묻는다.
1. 병목이 없었다면 이 사람은 한국을 선택했을 가능성이 얼마나 달라졌는가?
2. 한국을 선택하지 않았다면 어디로 갔는가?
3. 다른 곳으로 간 것이 아니라 여행 자체를 취소했는가?
4. 한국 방문은 유지했지만 상품·지역만 바꿨는가?
5. 그 차이가 실제 추가매출로 이어질 수 있었는가?

## 개념식
관측된 실현수요와 미실현수요를 분리한다.

총 유효수요 후보 = 실제 실현수요 + 검증 가능한 미실현수요

단, 미실현수요는 단순 검색량이 아니라 '의도 또는 시도 + 실패·대체 근거'가 있어야 한다.

병목별 잠재 추가수요는 다음처럼 본다.
잠재추가수요 = 해당 병목에 노출된 유효 시도 수 × 병목 제거 시 증가할 것으로 추정되는 성공확률

두 값 모두 분모와 인과근거가 없으면 계산하지 않는다.

## 기존 축과 연결
- 선택·후보집합: 후보편입과 탈락을 제공
- 예산·지불의사: 가격 때문에 탈락한 수요를 분리
- 수용량·재고: 매진 때문에 발생한 포기를 분리
- 검색: 관심은 있었지만 예약으로 이어지지 않은 경로
- 예약·결제: 실제 시도와 실패
- 이동: 이동불편 때문에 지역·상품이 대체된 경우
- 실패여정: 실패사유와 우회경로
- 경쟁목적지: 실제 대체 후보
- 시간축: 비자·환율·항공·계절 변화에 따른 대체구조 변화

## 사업기회 유형
- 한국 후보편입률은 높지만 실제 선택률이 낮은 시장
- 한국 선택의향은 높지만 항공·비자·가격 때문에 경쟁국으로 빠지는 시장
- 한국에는 왔지만 지방 이동마찰로 서울에서 소비가 대체되는 경우
- 높은 상품의향이 있으나 재고·예약·결제 때문에 다른 상품으로 대체되는 경우
- 반복적으로 여행을 연기하는 수요군

## 왜곡 방지
1. 경쟁국 방문자를 자동으로 한국의 잃어버린 고객으로 계산하지 않는다.
2. 검색량을 미실현수요 총량으로 사용하지 않는다.
3. 실패사례 건수를 실패율로 사용하지 않는다.
4. '여행 안 감'과 '다른 나라 감'을 분리한다.
5. 잠재수요와 실제 지불가능수요를 분리한다.
6. 반사실 추정에는 불확실성 범위를 반드시 붙인다.

## 공개자료 한계
공개통계는 실제 방문과 실제 지출에는 강하지만, 개인별 후보집합·탈락이유·대체목적지·무여행 결과를 함께 장기 추적하는 자료는 제한적이다. 잠재방한여행객 조사, 경쟁국 자료, 검색·가격·항공·비자 변화는 보조센서로 사용하고, 실제 대체율은 패널·현장조사·행동자료 또는 준실험이 필요하다.
