# 전체 프로젝트 완성도 재산정 — 2026-08-28

## 평가 원칙
설계문서의 존재와 실제 데이터 확보를 같은 완성도로 계산하지 않는다. 공개자료원 발견, 실제 원자료 적재, 현장관측, 자체 행동계측, 민간자료, 인과실험, 최종 공식 학습을 분리한다.

## 현재 객관적 판정
- 개념적 세계모형: 95% ±1% — 25개 기본축과 8개 교차계층으로 여행 전·중·후, 공급, 실패, 미실현수요, 개입, 불확실성까지 포괄한다.
- 측정·자료구조 설계: 93% ±2% — 무엇을 어떤 단위로 관측하고 무엇을 서로 같다고 보면 안 되는지 대부분 정의됐다.
- 공개 자료원 발견·근거 설계: 90~93% — 주요 국내외 공식·기업·연구 자료원이 확보됐으나 국가·기간·축별 빈칸은 남는다.
- 공개 원자료 실제 적재·정합화: 55~60% — 장기 월별 대량 적재와 국가간 정의 통일이 아직 큰 작업이다.
- 실제 행동·거래 자료: 20~30% — 검색→후보→예약→결제→방문과 실패분모, 실시간 재고 등은 부족하다.
- 현장조사: 초기 단계 — 조사설계는 있으나 전국 실행은 미완료다.
- 인과실험·개입성과: 초기 단계 — 설계는 있으나 충분한 실제 비교결과가 없다.
- 최종 경험적 공식: 0% 확정 — 공식의 형태를 설계할 수는 있으나 실제 결과자료로 계수와 가중치를 학습하기 전에는 확정하지 않는다.

## 실전 엔진 종합완성도
현재는 약 62~66%로 판정한다. 이 수치는 설계완성도를 그대로 평균낸 값이 아니라 실제 운영에 필요한 데이터·검증·실험의 부족을 반영한 보수적 범위다.

## 새롭게 확정한 작업순서
1. 통합 마스터를 25축+8교차계층 기준으로 유지하고 이후 설계변경은 중대한 새 근거가 있을 때만 한다.
2. 25축 상태표와 8교차계층 상태표를 실제 데이터 부족과 설계 부족으로 명확히 구분한다.
3. 2015~2025 또는 확보 가능한 최장기간의 월별 원자료를 출발국×지역×업종×여정단계 기준으로 대량 적재한다.
4. 상위15 출발국 정부 원자료와 한국 자료를 같은 정의·월 단위로 정합화한다.
5. 일본·대만·태국 등 경쟁목적지의 항공·숙박·가격·비자·검색·선택 자료를 동일 시간축으로 맞춘다.
6. 검색→후보편입→예약시도→결제→방문 전환과 각 단계 실패분모를 실제 행동자료로 확보한다.
7. 실제 판매가능 공급을 날짜·시간·일행·언어·채널·가격·결제가능성 단위로 관측한다.
8. 현장조사를 실행해 공개자료로 보이지 않는 판매의사, 언어대응, 결제, 마지막 이동구간, 실제 실패이유를 검증한다.
9. 자체 서비스 계측을 구현해 개인식별정보를 최소화하면서 행동사건과 거래결과를 측정한다.
10. 플랫폼·결제·환전·수수료·환불·정산·원가·마진·지역잔존가치를 실제 단위경제 자료로 보강한다.
11. 병목별 해결개입을 작은 시범사업으로 실행하고 비교집단 또는 적절한 준실험으로 실제 상승효과를 측정한다.
12. 모든 추정값에 불확실성 범위와 민감도 검사를 붙인다.
13. 충분한 결과자료가 쌓인 뒤에만 최종 경험적 공식과 가중치를 학습하고 시간외 검증한다.

## 금지 규칙
- 설계가 존재한다는 이유로 실제 데이터가 완성됐다고 표시하지 않는다.
- 경쟁국 방문을 한국의 손실수요로 자동 간주하지 않는다.
- 매진을 높은 수요로 자동 간주하지 않는다.
- 실제 지출을 예산 또는 최대지불의사로 간주하지 않는다.
- 동행자를 의사결정자나 결제자로 자동 간주하지 않는다.
- 사회관계망 조회수를 실제 방한수요로 간주하지 않는다.
- 병목과 사업기회를 같은 것으로 간주하지 않는다.
- 상관관계를 인과관계로 표현하지 않는다.
- 단일 신뢰점수만으로 불확실성을 숨기지 않는다.

## 언어 규칙
사람이 읽는 설명문, 상태표, 핵심 규칙은 한국어를 기본으로 한다. 국제 표준 약어, 고유 서비스명, 코드·필드명처럼 번역하면 연결성이 깨지는 경우에만 원어를 병기한다. 영어만으로 된 설명을 새로 만들지 않는다.
