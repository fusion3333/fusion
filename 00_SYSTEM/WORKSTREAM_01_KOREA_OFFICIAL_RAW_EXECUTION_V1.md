# 1번 작업 — 한국 공식 원자료 대량 적재 실행계획 V1

기준일: 2026-08-28

## 목표
한국 인바운드 관광 기회지능 엔진의 기준축을 한국 공식 원자료로 고정한다. 단순 링크 수집이 아니라 `원출처 → 측정정의 → 시간/공간/시장 입도 → 원자료 → 정규화 → 품질표시 → 엔진 축`까지 연결한다.

## 이번 검증에서 확정한 공식 접근경로

### A. 한국관광 데이터랩
- 한국관광공사 운영.
- CSV/Excel 다운로드 흐름이 존재한다.
- 관광통계와 관광 빅데이터의 공식 기준축으로 사용한다.
- 다운로드 화면의 자료설명·갱신·수정 이력을 원자료와 함께 보존한다.

### B. TourAPI / 공공데이터포털
- 한국관광공사 국문 관광정보서비스: REST, JSON/XML, 무료, 실시간 갱신.
- 지역코드, 분류코드, 법정동코드, 지역기반 관광정보, 위치기반 관광정보, 키워드검색, 행사, 숙박, 공통/소개/반복/이미지, 동기화 목록 등 15종 약 26만 건 수준의 관광정보를 제공한다고 공식 명세가 설명한다.
- 공급 통합의 공식 기준 엔터티 층으로 사용한다.

### C. 지역별 관광 다양성 API
- 관광객 다양성, 관광소비 다양성, 국제적 다양성의 3종 API.
- 신용카드·이동통신·내비게이션 기반 관광수요지수의 세부 지표라는 측정 성격을 보존한다.
- 외국인 소비액, 국적별 방문자 수, 방문객 국적 다양성 등은 행정 입국통계와 동일한 센서가 아니므로 별도 관측치로 유지한다.

### D. KOSIS
- 통계목록, 통계자료, 대용량통계자료, 통계설명, 통계표설명을 JSON/SDMX/XML/XLS 등으로 제공하는 공식 API 체계를 확인.
- 관광 관련 국가승인통계와 거시 보정변수의 원출처/교차검증 층으로 사용한다.

## 절대 합치지 않는 센서
1. 출입국/관광통계 방문자 수 ≠ 이동통신 기반 방문추정.
2. 설문 총지출 ≠ 카드 관측소비.
3. 내비 검색 ≠ 실제 방문.
4. 등록 관광사업체 ≠ 실제 영업 ≠ 외국인 판매가능 공급.
5. 관광콘텐츠 엔터티 ≠ 사업체 인허가 엔터티.
6. 지수/다양성 점수 ≠ 원시 거래액·방문자 수.

## 목표 데이터군
| 데이터군 | 목표 입도 | 엔진축 | 현재 상태 |
|---|---|---|---|
| 월×국가 방한통계 | YYYY-MM×출발시장 | 누가/언제/출발국 | 공식 다운로드 흐름 검증, 실제 전기간 행 적재 필요 |
| 외래관광객조사 | 응답자×조사연도 | 누가/왜/숙박/활동/지출/불편/만족 | 원자료·코드북 연도 정합화 필요 |
| 이동통신 방문·체류 | 기간×지역×시장/속성(공개범위) | 이동/체류 | 센서 정의 보존 후 적재 필요 |
| 외국인 카드 관광소비 | 기간×지역×업종×시장(공개범위) | 지출/돈 | 카드층과 공통키 연결 필요 |
| 내비게이션 검색 | 기간×지역×검색대상 | 검색/이동 | 검색의도 센서로만 사용 |
| 관광사업체/숙박 | 사업체×지역×유형 | 공급/숙박 | 등록 기준축, 운영여부 별도 |
| TourAPI 관광콘텐츠 | 콘텐츠×지역×분류 | 공급/활동/숙박 | API 전량 동기화 대상 |
| 관광 다양성 | 기간×지역×세부지표 | 지역/국제/소비 다양성 | 원시값과 분리된 파생지표 |

## 적재 원칙
- 원자료 파일은 가능한 원형 보존.
- `source_url`, `source_agency`, `retrieved_at`, `published_at/revised_at`, `measurement_method`, `unit`, `coverage`, `missing_reason` 필수.
- 없는 월/국가/지역은 0으로 채우지 않는다.
- 수정된 공식통계는 원버전과 수정버전을 구별하거나 revision 필드를 남긴다.
- API 호출이 인증키/로그인을 요구하면 키를 저장소에 넣지 않는다.
- 공개 다운로드가 사용자 동작/설문을 요구하는 경우 우회하지 않고 접근제약으로 기록한다.

## 완료조건
1. 한국 공식 핵심 데이터군별 실제 원자료 또는 API 행이 저장소에 존재.
2. 최소 2015~현재를 목표로 월 시계열을 확보하되 공식 공개기간이 짧으면 그대로 기록.
3. 각 데이터군의 정의·단위·센서·수정정책이 기록됨.
4. 공통 시간·지역·출발시장 키로 조인 가능.
5. 센서 간 직접 합산 금지 규칙이 적용됨.
6. 접근 불가/인증 필요/유료/비공개를 결측과 구별.

`SOURCE_CONTRACT_VERIFIED / BULK_ROWS_NOT_YET_EXHAUSTED`
