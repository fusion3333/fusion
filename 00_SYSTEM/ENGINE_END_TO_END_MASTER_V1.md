# 한국 인바운드 관광 기회지능 엔진 — 통합 마스터 V2

## 목적
출발국에서 한국을 인지하는 순간부터 여행 후 행동과 다음 사람에게 미치는 영향까지 전체 여정을 모델링한다. 이를 한국의 공급·유통·결제·이동·지역 가치사슬과 대조하여 끊긴 연결, 비싼 연결, 접근 불가능한 공급, 실패 여정, 미실현 수요를 찾아내고 실제 사업·정책 개입으로 전환한다.

## 핵심 원칙
1. 사실 정확성이 범위보다 우선한다.
2. 비율보다 분모를 먼저 확인한다.
3. 점수보다 출처와 측정방식을 먼저 기록한다.
4. 사업기회보다 실제 격차를 먼저 검증한다.
5. 사업화보다 해결가능성과 경제성을 먼저 검증한다.
6. 가중치보다 실제 결과를 먼저 관측한다.
7. 관측값과 추정값, 상관관계와 인과관계를 분리한다.
8. 공개자료로 알 수 없는 것은 모른다고 남긴다.

### 공급·유통

### 진단

### 의사결정
사업·정책 기회

전체 계층 통합 / 실제 결과를 이용한 경험적 공식 학습

## 8개 교차계층
1. 목적지 후보·선택: 한국 인지→후보편입→비교→선택→탈락·대체를 구분한다.
2. 동행집단 의사결정: 여행자, 기획자, 검색자, 영향자, 최종결정자, 예약자, 결제자, 동행자, 자녀·부양자 등을 분리한다.
3. 예산·지불의사·가격반응: 실제 지출과 여행 전 예산, 최대 지불의사, 가격변화에 대한 반응을 분리한다.
4. 수용량·재고·시간: 등록된 공급과 특정 날짜·시간·일행·채널에서 실제 판매 가능한 공급을 분리한다.
5. 네트워크효과·사회적확산: 경험→리뷰·영상·추천→다른 사람의 인지·검색·선택으로 이어지는 순환을 측정한다.
6. 반사실·미실현수요: 한국을 선택하지 않은 사람, 경쟁국으로 바꾼 사람, 예약포기, 여행취소와 병목이 없었을 경우의 잠재수요를 구분한다.
7. 개입비용·인과효과: 병목을 고쳤을 때 실제 전환·매출·이익이 얼마나 늘어나는지와 해결비용을 함께 검증한다.
8. 불확실성분해: 표본오차, 측정오차, 출처편향, 결측, 정의차이, 모형차이, 시간노후화, 인과식별 불확실성을 분리한다.

## 반드시 구분할 것
등록 객실 수 ≠ 오늘 실제 예약 가능한 객실 수
영업 중 ≠ 원하는 날짜·시간에 이용 가능
운영 일정 존재 ≠ 특정 판매채널에서 예약 가능
플랫폼 잔여석 존재 ≠ 해당 일행이 예약 가능
화면상 예약 가능 ≠ 실시간 예약 확정 가능
물리적 최대수용량 ≠ 품질·안전·보존을 고려한 적정수용량
매진 ≠ 반드시 높은 수요
실제 지출 ≠ 여행예산 ≠ 최대지불의사
조회 ≠ 관심 ≠ 검색 ≠ 후보편입 ≠ 선택 ≠ 예약 ≠ 실제방문
경쟁국 방문 ≠ 한국에서 경쟁국으로 전환
동행자 ≠ 기획자 ≠ 결제자 ≠ 최종결정자
병목 발견 ≠ 사업기회
상관관계 ≠ 인과효과
점추정치 ≠ 확정된 진실

- 공개근거·관측·지식그래프 구조
- 현장조사·자체계측·진단·기회평가·통합학습 절차
- 8개 교차계층의 개념 및 측정 설계

## 아직 완료되지 않은 것
- 장기 원자료의 대량 적재와 국가·월·지역·업종 기준 정합화
- 전국 공급자 현장조사
- 실제 이용자 행동·거래 계측
- 민간 플랫폼 내부 검색·예약·결제·재고·수수료 자료
- 실제 개입실험과 비교집단 성과
- 결과값으로 학습된 최종 경험적 가중치와 공식

따라서 '설계가 거의 완성되었다'와 '실전 엔진이 완성되었다'를 혼동하지 않는다.

## 최종 산출물
최종 기회객체는 최소한 다음 질문에 답해야 한다.
누가 무엇을 왜 원하는가 / 언제 어디에서 원하는가 / 누가 실제 결정을 내리고 돈을 내는가 / 한국과 경쟁국 중 무엇을 고려했는가 / 어디서 실패하는가 / 실제 판매 가능한 공급은 얼마인가 / 얼마까지 지불할 가능성이 있는가 / 어떤 수요가 실현되지 않았는가 / 무엇을 고치면 결과가 얼마나 개선되는가 / 해결비용과 순경제가치는 얼마인가 / 지역에 남는 가치는 얼마인가 / 추정의 불확실성은 얼마인가 / 모든 판단의 근거와 출처는 무엇인가.
