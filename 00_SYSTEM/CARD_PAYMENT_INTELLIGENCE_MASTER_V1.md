# 카드·결제 지능층 마스터 V1

기준일: 2026-08-28

## 목적
관광객의 실제 거래를 `출발국 → 카드/결제망 → 목적지 → 지역 → 업종/상품 → 거래건수 → 거래액 → 객단가 → 결제경로 → 환율/수수료 → 공급자 정산`으로 연결한다.

이 계층은 기존 지출, 예약·결제, 돈의 흐름, 출발국 상위15, 경쟁목적지, 실패여정을 가로지르는 실제 거래 센서다.

## 절대 혼합 금지
- 특정 카드사 소비 ≠ 전체 카드소비
- 전체 카드소비 ≠ 전체 관광지출
- 승인 거래액 ≠ 여행예산 ≠ 최대 지불의사
- 카드 발급국 ≠ 국적 ≠ 거주국
- 카드 사용 지역 ≠ 숙박 지역 ≠ 실제 방문 전체 동선
- 카드 거래건수 ≠ 관광객 수
- 해외 온라인 결제 ≠ 목적지 현장 관광소비
- 환불 전 승인액 ≠ 최종 순매출
- 카드망 관측점유율 ≠ 시장 전체 점유율
- 국내발급카드 해외사용액 ≠ 해외여행 소비액. 전자상거래·구독·디지털서비스가 섞일 수 있다.

## 표준 관측 단위
가능한 경우 다음을 보존한다.
`기간, 출발국/발급시장, 목적국, 목적지역, 업종, 상품/가맹점, 카드망, 발급/매입기관, 채널, 대면여부, 전자상거래여부, 거래건수, 총거래액, 환불액, 순거래액, 통화, 환율기준, 객단가, 수수료규칙, 관측범위, 관측시점, 방법론, 미포착범위, 원출처, 불확실성메모`.
없는 값은 추정해서 채우지 않는다.

## 데이터군
### 1. 한국 인바운드 카드소비
한국관광 데이터랩 외국인 신용카드 관광소비, 외국인 간편결제 관광소비, 카드사/매입사/데이터사업자의 공개자료, 정부·지자체의 카드 기반 관광소비를 우선한다. 특정 카드 관측치를 전체 관광소비로 확대할 때는 별도 추정과 불확실성 범위가 필요하다.

### 2. 글로벌 카드망
Visa, Mastercard, American Express, JCB, UnionPay, Discover/Diners의 관광·경제·결제 데이터 상품과 공개 보고서를 `공개 무료 원자료 / 공개 보고서 / 제한 API / 상업제품 / 제휴필요 / 미확인`으로 분류한다.

### 3. 출발국 상위15 카드 거울
일본, 중국, 대만, 미국, 홍콩, 필리핀, 베트남, 싱가포르, 인도네시아, 태국, 말레이시아, 캐나다, 호주, 러시아, 영국에 대해 중앙은행·금융감독기관·카드협회·공동처리망·통계기관·주요 카드망의 해외사용 자료를 조사한다.

### 4. 경쟁목적지 외국카드 소비
일본·대만·태국·싱가포르·베트남·홍콩에서 외국카드 사용의 금액·건수·업종·지역을 확보해 한국과 비교한다.

## 현재 공식 검증된 강한 공개자료
### 한국
한국관광 데이터랩에서 외국인 신용카드 관광소비와 외국인 간편결제 관광소비를 확인했다. 지역·국가·업종 분석에 강하지만 카드관측 범위와 온라인예약서비스 제외 등 정의를 보존해야 한다.

### 대만
NCCC는 외국 카드소지자의 대만 내 신용카드 소비를 52개 CSV 항목으로 매월 갱신한다. 음식, 의류, 숙박, 교통, 문화·오락, 백화점, 전체, 지역, 전자상거래 금액·건수가 포함된다. 대만 카드소지자의 해외소비 상위10 및 국경간 소비자료도 공개한다.

### 태국
태국 중앙은행은 2016년부터 태국 발급 전자카드의 해외사용을 월별 공개한다. 신용/직불, 대면점포/온라인, 현금인출 등을 분리한다. 반대로 외국발급 카드·전자화폐의 태국 내 사용도 월별 공개한다. 이는 출발국 거울과 경쟁목적지 인바운드 카드센서를 동시에 제공한다.

### 홍콩
홍콩금융관리국은 홍콩 발급 신용카드의 국내사용과 해외사용 거래건수·금액을 분리한 분기 통계를 공개한다. 카드 대출조사 API도 있으나 관광분석에는 해외사용 통계가 더 직접적이다.

### 말레이시아
말레이시아 중앙은행은 월별 신용카드 운영·직불카드 거래 통계를 XLS로 공개하며, 국내 금융기관 발급카드의 `Transactions Abroad`를 국내거래와 분리 정의한다. 전자상거래 포함 여부를 별도 확인하면서 사용해야 한다.

### 영국
영국 통계청은 Visa와 협약해 집계·익명화 카드자료를 이용한다. 영국 거주자 카드의 해외 가맹점 소비를 국가/지역 및 온라인·대면으로 분석한 2019~2025 공개 분석이 있고, 영국 내 국제방문객의 Visa 대면 소비도 관광업종 기준으로 분석한다. Visa 카드범위이므로 전체소비로 확대하지 않는다.

### 러시아
러시아 중앙은행 국가결제시스템 통계에는 러시아 발급 카드의 러시아 내·외 거래가 포함된다. 다만 2022년 3월 이후 러시아 은행 발급 Visa/Mastercard의 해외·해외온라인 사용이 중단되는 구조적 단절이 있으므로 전후를 같은 시계열로 처리하면 안 된다.

### 호주
호주 중앙은행은 월별 소매결제 통계와 카드별 국제카드 가맹점 수수료를 공개한다. 현재 확인한 공개면은 호주 발급카드 총구매와 국제카드 가맹점 수수료에는 강하지만, 목적국별 해외관광 소비는 별도 공개경로가 더 필요하다.

### 일본
일본은행 국제수지 여행계정 방법론은 여행수지 산출에 신용카드 국내/해외 사용액을 포함한다고 명시한다. 그러나 공개 여행수지는 카드 원거래 패널이 아니라 여러 자료를 결합한 거시통계이므로 카드 원자료로 취급하지 않는다.

## 글로벌 카드망 공식 검증
### Visa
Visa Spend Signals는 집계·비식별 Visa 대면결제를 기반으로 일 단위, 출발시장, 우편번호/도시/지역, 업종, 계절성, 경쟁지 비교 등을 제공한다. 대시보드와 API가 존재하지만 제한/상업 접근이다.

### Mastercard
Mastercard Tourism Insights는 소비자료와 제3자 검색·예약·숙박·사회관계망 자료를 결합해 여행 전주기를 분석하는 상업제품이다. 공개 무료 원거래 패널로 취급하지 않는다.

### UnionPay
UnionPay International은 중국인 해외여행 소비 및 수용망에 관한 공식 보고서·협력자료를 공개해 왔고, Ctrip과 결제자료를 결합한 중국 해외여행 소비보고서도 발행했다. 그러나 최신 연속 원거래 패널의 공개 무료 제공은 확인되지 않았다. 보고서/제휴자료 센서로 분리한다.

### American Express / JCB / Discover-Diners
공개 관광동향·기업자료는 존재하지만, 본 프로젝트가 요구하는 장기 월×출발국×목적지×업종 원거래 패널의 무료 공개 여부는 아직 확인되지 않았다. 확인될 때까지 미확인으로 둔다.

## 카드 데이터가 답할 질문
1. 어느 출발시장의 실제 소비가 어느 지역·업종으로 이동하는가?
2. 방문객 증가와 소비 증가가 같이 움직이는가?
3. 객단가가 높은 시장은 어디인가?
4. 특정 시장에서 숙박·교통·체험·쇼핑 구성은 어떻게 다른가?
5. 경쟁목적지 대비 한국의 카드소비 포획력이 어떻게 변하는가?
6. 결제수단·해외카드·환율·수수료·환불 마찰이 구매전환을 막는가?
7. 관광객 지불액 중 플랫폼·결제·환전 비용을 거쳐 공급자와 지역에 얼마가 남는가?
8. 카드소비와 방문객 수가 엇갈리는 시장은 어디인가?
9. 현금/QR/간편결제 전환 때문에 카드센서가 놓치는 시장은 어디인가?

## 실행 순서
1. 한국 카드/관광소비 원자료 등록·적재
2. 태국·대만·홍콩·말레이시아 등 강한 공개 카드시계열 우선 적재
3. 글로벌 카드망 공식 데이터제품 전수등록
4. 상위15 출발국 공개카드 자료 전수조사
5. 경쟁목적지 외국카드 소비자료 전수조사
6. 공통 스키마 정합화
7. 월×출발국×목적지×지역×업종 패널 생성
8. 관광객 수·숙박·이동·검색·환율·항공 패널과 연결
9. 돈의 흐름·결제실패·실제판매가능공급 계층에 연결
10. 카드센서별 대표성 보정과 불확실성 분해

## 품질 규칙
모든 데이터행에 관측범위, 대표성, 발급국/거주국/국적 정의, 카드망 범위, 현금·계좌이체·간편결제 미포착, 온라인 거래 포함여부, 환불 반영여부, 명목/실질 금액, 갱신일, 시계열 단절을 가능한 한 기록한다.

## 현재 상태
- 설계: 완료
- 한국: 공식 관광카드 소비경로 확인
- 대만: 강한 월별 공개 CSV 확인
- 태국: 인바운드/아웃바운드 월별 카드 공개통계 확인
- 홍콩: 해외사용 분리 분기통계 확인
- 말레이시아: 국내발급카드 해외거래 월별 통계 확인
- 영국: Visa 기반 국가/채널별 해외소비 공개분석 확인
- 러시아: 국내/해외 카드통계와 2022 체제단절 확인
- 호주: 월 소매결제·국제카드 수수료 공개통계 확인
- 일본: 여행수지 카드사용 포함 방법론 확인, 원카드 패널은 미확인
- 기타 상위15 국가: 공개 원거래 패널 추가 탐색 필요
- 최종 카드시장 보정계수: 실제 커버리지 검증 전까지 미확정
