# BOOK/PAY Graph V1

## State graph
`SEARCH/DETAIL → INVENTORY_VISIBLE → BOOK_STARTED → REQUIREMENTS_PASSED → PRICE_TERMS_ACCEPTED → PAY_STARTED → AUTHENTICATED → AUTHORIZED → BOOK_CONFIRMED → SERVICE_CONSUMED → AFTER_SALES`

Failure edges are first-class:
- `INVENTORY_VISIBLE -X→ BOOK_STARTED`
- `BOOK_STARTED -X→ REQUIREMENTS_PASSED`
- `REQUIREMENTS_PASSED -X→ PRICE_TERMS_ACCEPTED`
- `PAY_STARTED -X→ AUTHENTICATED`
- `AUTHENTICATED -X→ AUTHORIZED`
- `AUTHORIZED -X→ BOOK_CONFIRMED`
- `CANCEL_REQUESTED -X→ REFUND_COMPLETED`

## Failure taxonomy
NO_INVENTORY; SOLD_OUT; FOREIGNER_INELIGIBLE; DOMESTIC_PHONE_REQUIRED; DOMESTIC_ID_REQUIRED; DOMESTIC_ACCOUNT_REQUIRED; LANGUAGE; PRICE_SHOCK; FEE_SHOCK; CARD_UNSUPPORTED; ISSUER_DECLINE; AUTHENTICATION_FAILURE; FX_DCC; APP_ERROR; SESSION_TIMEOUT; CONFIRMATION_FAILURE; REFUND_RULE; REFUND_DELAY; CHARGEBACK; UNKNOWN.

## Edge metadata
Every edge must carry: `OBSERVED|INFERRED|PROXY|IMPUTED|UNKNOWN`, source class O/E/S/R/G/N, timestamp/regime, operator, product, channel, traveler origin/segment if available, denominator status.

## Core denominator metrics (only when N/E data exist)
`BookStartRate = BOOK_STARTED / QUALIFIED_DETAIL_VIEWS`
`BookCompletionRate = BOOK_CONFIRMED / BOOK_STARTED`
`PaymentStartRate = PAY_STARTED / PRICE_TERMS_ACCEPTED`
`PaymentSuccessRate = AUTHORIZED / PAY_STARTED`
`AuthenticationFailureRate = AUTH_FAILURE / PAY_STARTED`
`AuthorizationDeclineRate = DECLINED / AUTHENTICATED`
`RefundCompletionRate = REFUND_COMPLETED / REFUND_REQUESTED`

No metric is computed when numerator/denominator populations are not definitionally aligned.
