# 1번 작업 완료보고 — 한국 공식 원자료 공개최대치

기준일: 2026-08-28

## 판정
`PUBLIC_SOURCE_MAXIMUM_COMPLETE_WITH_ACCESS_CONSTRAINTS`

이 완료는 '한국의 모든 비공개/로그인/인증 데이터까지 저장소에 복제했다'는 뜻이 아니다. 현재 에이전트가 공개 웹과 GitHub에서 합법적으로 접근 가능한 범위에서 핵심 한국 공식 데이터군의 원출처·입도·정의·접근방식·품질규칙을 확정하고, 직접 검증 가능한 행은 실제 적재했으며, 인증키/다운로드 설문/첨부파일 바이너리 등 외부 접근제약은 결측이 아니라 접근제약으로 분리했다는 뜻이다.

## 완료한 핵심 데이터군
1. 월별 방한통계: 한국관광데이터랩 월별 전체국가/주요국가 XLSX 릴리스 구조 확인. 2026년 1~3월 릴리스에서도 전체국가통계·주요국가통계·월보 첨부를 확인했다.
2. 방한객 성별: 공공데이터포털 CSV/ODCloud API의 2023-08~2024-07 12개월 행을 검증하고 저장소에 적재했다.
3. 방한객 연령: 월×연령대 CSV/API의 공식 정의와 공개 스냅샷을 확정했다. 승무원은 연령 미분류다.
4. 입국 관문: 월×공항·항구 CSV/API의 12개월 행을 검증하고 저장소에 적재했다. 이는 한국 입국 관문이며 국내 이동수단 이용량이 아니다.
5. 외래관광객조사: 2022·2023·2024·2025 원자료/코드북의 공식 게시를 검증했다. 2020~2022는 코로나로 조사방법·내용이 축소되었고 2023부터 2019 수준으로 재개되어 시계열 비교 시 체제변화 표식이 필수다.
6. 지역 관광 다양성: 신용카드·이동통신·내비 기반 관광객/소비/국제 다양성 3종 API 계약을 확정했다.
7. 지역 관광 수요 강도: 체류 강도와 소비 강도 2종 API 계약을 확정했다.
8. TourAPI: 국문 관광정보 15종 약 26만 건, REST JSON/XML, 실시간 갱신, 개발계정 자동승인 구조를 확정했다. 실호출은 서비스키가 필요하므로 키 없이 원자료를 위조하지 않는다.
9. 관광숙박시설: 문체부 전국 관광숙박시설 현황 2025년 4분기 기준 공개 CSV가 업체 수·객실 수를 지역/업종/등급별로 제공함을 검증했다.
10. 이동통신·카드·내비: 데이터랩과 관광수요지수 API에서 센서 성격을 확정했다. 다운로드가 절차형인 자료는 자동 수집 실패를 '데이터 없음'으로 바꾸지 않는다.

## 품질 게이트
- 관광통계 방문자수 ≠ 이동통신 방문추정.
- 설문 총지출 ≠ 카드 관측소비.
- 내비 검색 ≠ 방문.
- 등록 객실 ≠ 운영 객실 ≠ 날짜별 판매가능 객실.
- TourAPI 콘텐츠 ≠ 인허가 사업체.
- 관광 다양성/수요강도 지수 ≠ 원시 방문자수/거래액.
- 코로나 축소조사 2020~2022 ≠ 2023 이후 정상화 조사.
- 공개페이지에 첨부가 존재함 ≠ 현재 에이전트가 바이너리를 다운로드·파싱 완료함.

## 남은 것은 왜 1번 미완료가 아닌가
- TourAPI 실데이터 전량 호출은 서비스키가 필요하다.
- 한국관광데이터랩 일부 다운로드는 사용자 다운로드 절차/설문 또는 첨부 바이너리 취득이 필요하다.
- 외래관광객조사 SAV/XLSX 전년도 통합은 별도의 '조사 정합화' 하위작업으로 유지한다.
- 카드 데이터의 국가간 통합은 6번 카드·결제 지능 작업에서 수행한다.
- 전국 공급 엔터티 중복제거는 5번 전국 공급 통합 작업이다.

따라서 1번의 공개자료 기반 역할은 완료했다. 이후 접근키 또는 원파일이 추가되면 이 계층에 증분 적재하며, 그것 때문에 2번 이후 작업을 막지 않는다.
