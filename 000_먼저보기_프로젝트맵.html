한국 인바운드 관광기업간 거래형 의사결정사람 행동공급·플랫폼·돈기회 탐지

한국 인바운드 관광산업에서
“아직 연결되지 않아 돈이 되지 못한 가치”를 찾는 전체 지도

이 프로젝트는 관광객 수를 보여주는 통계 화면이 아닙니다. 사람이 왜 여행을 원하고 → 왜 한국을 후보에 넣고 → 무엇과 비교하고 → 어떻게 검색·예약·결제하고 → 한국에서 어디로 이동해 무엇을 경험하고 → 어디서 실패하며 → 돈이 어디로 흘러가고 → 여행 후 무엇을 공유하는지를 한국의 실제 공급과 연결해, 고칠 가치가 있는 병목과 사업기회를 찾는 의사결정 엔진입니다.

한 문장 목표
“누가 무엇을 원하는데 왜 아직 거래가 일어나지 않는가, 그 연결을 고치면 얼마의 가치가 새로 생기는가?”를 근거와 불확실성까지 포함해 설명하는 것.

1. 왜 이런 거대한 구조가 필요한가

문제 1 — 한 기관은 한 조각만 본다

출입국은 입국을, 카드자료는 카드 소비를, 통신자료는 이동 추정을, 예약플랫폼은 자기 플랫폼의 예약을, 사회관계망은 관심과 이야기를 봅니다. 어느 하나도 여행 전체를 보지 못합니다.

문제 2 — “존재”와 “판매 가능”은 다르다

한옥·공방·식당·체험이 등록되어 있어도 외국어 정보, 검색 노출, 예약, 해외카드, 이동, 실시간 재고가 막히면 외국인에게는 사실상 없는 공급입니다.

문제 3 — 온 사람만 보면 잃은 수요가 안 보인다

한국을 후보에서 뺀 사람, 일본으로 바꾼 사람, 결제 직전에 포기한 사람, 가고 싶었지만 교통 때문에 못 간 사람은 일반 방문통계에서 사라집니다.

문제 4 — 불편이 곧 사업기회는 아니다

불편이 커도 수요가 작거나 해결비용이 너무 크면 사업이 아닙니다. 수요·지불의사·해결가능성·경쟁·마진·인과효과를 함께 봐야 합니다.

그래서 우리는 공식통계 + 출발국 정부자료 + 기업·플랫폼 자료 + 검색·후기·사회관계망 + 학술연구 + 현장조사 + 자체 행동·거래자료를 같은 정의체계 안에서 연결합니다.

2. GitHub 저장소는 무엇을 어디에 두는가

현재 저장소의 핵심 흐름은 아래와 같습니다. 과거 연구가 들어 있는 .k전통플랫폼과 현재 운영 구조인 00_SYSTEM → 01_L1_EVIDENCE → 02_L2_OBSERVATION(S) → 03_L3_GRAPH → 04_DATA가 함께 존재합니다. 과거 연구에는 인간행동, 자료원 우선순위, 여행자 생애주기 변수, 인과 디지털트윈, 경쟁사 역설계 등 현재 구조의 뿌리가 남아 있습니다.

왜: 기회는 단일 표보다 “연결이 끊긴 위치”에서 더 잘 보이기 때문.

4. 25개 기본축 — 목적·변수·소스·이유

아래 25축은 현재 프로젝트 운영 상태표의 기준입니다. 각 축은 하나의 질문이 아니라 여러 센서가 만나는 분석단위입니다.

1. 누가 오는가

목적

국적·거주국·연령·성별·소득/예산·첫방문/재방문·동행형태·여행숙련도 등 고객의 기본상태를 정의.

왜 필요한가

“미국인” 하나로 묶으면 20대 친구여행과 50대 부부의 욕구·예산·동선이 섞이기 때문.

핵심 소스
한국관광공사/한국문화관광연구원 외래관광객조사, 한국관광통계, 법무부 출입국, KOSIS, 각 출발국 정부통계. 향후 현장조사로 기획자·결제자·영향자 역할 보강.

2. 왜 여행하고 왜 한국인가 — 인간심리

목적

휴식·자기정체성·새로움·사회적 과시·관계·문화욕구 같은 인간동기와 K팝·드라마·음식·전통·웰니스·쇼핑 등 한국 선택동기를 연결.

왜

관광수요의 결과가 아니라 수요를 만드는 원인을 보기 위해.

소스
잠재 방한여행객 조사, 외래관광객조사, 한류 관련 공식조사, Google/YouTube/SNS 추세, 국가별 커뮤니티, 관광·심리 학술연구. SNS만으로 인구 전체 심리를 추정하지 않음.

3. 언제 움직이는가

목적

연도·월·계절·출발국 휴일·예약선행기간·항공좌석·정책·대형행사와 수요 변화를 연결.

왜

계절성과 구조적 변화, 일시적 사건효과를 구분하기 위해.

소스
월별 한국관광통계, 항공·공항 공식자료, 출발국 달력·휴일, 환율, 비자·정책·행사 기록.

4. 출발국 상위 15개국 거울

목적

한국에 들어온 숫자만 보지 않고 각 나라 국민의 전체 해외여행 중 한국의 위치를 확인.

왜

“한국 방문 증가”가 그 나라 해외여행 전체 증가 때문인지 한국 선호 증가인지 구분.

소스
일본 JNTO/정부, 미국 NTTO, 대만 관광·출입국 통계, 캐나다 Statistics Canada, 영국 ONS, 호주 ABS, 싱가포르 SingStat, 인도네시아 BPS, 필리핀 PSA 등 각국 정부. 중국·홍콩·베트남·말레이시아·러시아·태국은 공개 세분도 차이를 품질표시로 보존.

5. 경쟁목적지

목적

일본·대만·태국·싱가포르·베트남·홍콩 등과 한국을 같은 기준으로 비교.

왜

한국 자체 성장률만 보면 상대적 매력도와 대체효과를 놓치기 때문.

소스
JNTO, Taiwan Tourism Administration, 태국 관광체육부 공개자료, SingStat, 베트남 관광당국, 홍콩 관광통계 + 항공·숙박·비자·가격자료.

6. 검색

목적

어떤 언어로 무엇을 어느 채널에서 찾고, 비교하고, 포기하는지 측정.

왜

관심이 있어도 발견되지 않으면 거래가 일어나지 않기 때문.

소스
외래관광객조사 정보채널, 한국관광 데이터랩 내비·검색 관련 지표, Google Trends 등 공개 검색신호, Google Maps, OTA·공식 사이트, SNS·커뮤니티, 향후 자체 행동계측.

7. 예약·결제

목적

예약채널, 즉시확정, 취소·환불, 계정·본인인증, 해외카드, 환율·수수료, 승인·거절을 단계별로 분리.

왜

소스
외래관광객조사, OTA·항공·공급자 공식 정책, 카드·결제대행사 공개자료, 교통사업자 결제정책, 정부·서울시 등 공식결제 안내, 향후 실제 실패로그.

8. 이동

목적

입국공항에서 도시 간 이동, 지역 내 이동, 마지막 3~20km까지 외국인이 실제 이용 가능한지 확인.

왜

교통수단이 존재해도 언어·결제·예약·수하물·야간운행 때문에 접근하지 못할 수 있기 때문.

소스
한국관광 데이터랩 이동통신·내비 신호, 코레일/SR/공항철도, 버스·교통카드·도시철도·지자체 공개자료, 택시 공식자료·불편신고, 지도·모빌리티 플랫폼, 현장.

9. 숙박

목적

체류일수·지역별 숙박·숙소유형·가격·예약채널·실제 재고·언어·체크인마찰을 연결.

왜

등록 객실 수와 특정 날짜 외국인이 실제 살 수 있는 객실 수는 다르기 때문.

소스
외래관광객조사, 문체부 관광숙박 등록통계, 관광사업체·인허가, Booking/Agoda/Trip.com/Airbnb/Expedia 등 공개표면, 공급자 현장자료.

10. 활동·체험

목적

계획한 활동, 실제 활동, 원했지만 실패한 활동을 분리하고 가격·언어·예약·수용량·만족과 연결.

왜

숨은 전통문화·공방·한옥·다도·한의·웰니스 같은 ‘원석’의 재가치화 가능성을 찾기 위해.

소스
외래관광객조사, TourAPI/한국관광콘텐츠랩, 지자체·지역관광기관, Klook/KKday/Trazy/Viator/GetYourGuide, 공급자 사이트·SNS, 현장조사.

11. 지출

목적

총지출·업종별·지역별·1인당·1일당 소비와 결제경로를 세분.

왜

관광객 수가 아니라 실제 경제가치와 지역 잔존가치를 보기 위해.

소스

12. 불편·민원

목적

언어·예약·결제·환불·이동·택시·청결·안전·차별·정보부족 등의 실제 고통과 해결과정을 분류.

왜

사업기회의 출발점인 ‘마찰’을 찾되 리뷰의 표본편향을 통제하기 위해.

13. 만족·추천·재방문

목적

왜

소스

14. 공급

목적

한국에 실제 존재하는 관광·숙박·전통문화·음식·공예·웰니스·쇼핑·가이드·교통 자산을 통합.

왜

공급자 자체가 여러 정부·지자체·플랫폼에 흩어져 있기 때문.

소스
TourAPI, 문체부, 공공데이터포털, LOCALDATA 계열 인허가, 지자체·지역관광기관, 업체 공식사이트, 지도·OTA·SNS.

15. 실제 판매가능 공급

목적

등록 → 영업 → 발견가능 → 외국어 → 예약가능 → 해외결제 → 실제 재고 → 판매의사 → 재구성 가능으로 공급을 단계화.

왜

공식 공급 1,000개가 있어도 외국인이 살 수 있는 공급은 훨씬 적을 수 있기 때문.

소스
공식 공급목록 + Google/OTA 노출 + 공급자 공식사이트 + 실제 가격·재고 + 현장 전화·방문조사. 핵심 독자자료 후보.

16. 플랫폼

목적

검색·지도·예약·결제·후기·지원 단계에서 어떤 중개자가 고객접점을 소유하는지 확인.

왜

공급자와 관광객 사이 가치와 데이터가 플랫폼에서 새거나 막힐 수 있기 때문.

소스
Booking, Agoda, Trip.com, Expedia, Airbnb, Klook, KKday, Viator, GetYourGuide, Trazy, Google Maps/Travel, Naver/Kakao 등 공개정책·상점표면·파트너문서.

17. 돈의 흐름

목적

관광객 지불액 → 플랫폼 수수료 → 결제대행·환전 → 세금 → 공급자 매출 → 인력·물류·원가 → 마진 → 지역에 남는 가치 추적.

왜

매출이 커도 지역·공급자에게 남는 돈이 적으면 가치포획 문제가 있기 때문.

소스
플랫폼·결제·환전 공식요금, 세무·규제자료, 기업공시·사업보고서, 공급자 실제 원가·수수료 현장조사. 비공개 마진은 추정하지 않고 미확인으로 둠.

18. 10년×12개월 시간축

목적

가능한 모든 축을 월 단위 장기패널로 맞추되 자료가 분기·연간뿐이면 그대로 보존.

왜

코로나, 환율, 비자, 직항 신설, 콘텐츠 흥행, 계절·휴일 같은 충격의 시차를 보기 위해.

소스
각 축 공식 장기통계 + 환율·항공·정책·행사·플랫폼 변화 사건기록. 없는 월값을 임의 보간하지 않음.

19. 실패여정

목적

검색했지만 못 찾음, 예약했지만 실패, 결제 거절, 이동 포기, 매진, 환불 실패처럼 ‘시도했지만 실패’를 별도 사건으로 저장.

왜

성공한 거래만 보면 가장 큰 미실현수요가 사라지기 때문.

소스
공식민원, 플랫폼 정책·오류사례, 리뷰·커뮤니티, 공급자 면담, 향후 자체계측. 가장 부족한 것은 실제 시도분모.

20. 현장지능

목적

온라인으로 알 수 없는 외국인 비중, 실제 예약채널, 언어, 해외카드, 수용량, 공급자 고통, 협업·재구성 의향을 직접 확인.

왜

공식등록·플랫폼 노출만으로 실제 운영현실을 알 수 없기 때문.

방법
서울·경기 공급자 100곳 발굴, 상위 20곳 심층 전화/방문을 시범설계. 관광객의 실패·선택이유 면담도 별도.

21. 자체 행동·거래계측

목적

노출→클릭→검색→상세→비교→예약시작→결제→확정→방문→완료→환불→추천→재구매를 직접 측정.

왜

공개자료가 가장 약한 ‘시도분모’와 실제 전환을 확보하기 위해.

소스
향후 우리 서비스의 동의 기반 비식별 행동사건·거래대사. 현재 계측구조는 설계됐지만 실가동 전.

22. 고립·병목·정보비대칭

목적

좋은 공급이 네트워크에 연결되지 않은 고립, 전체 흐름을 막는 병목, 국내정보와 외국인 접근정보 차이를 진단.

왜

우리 사업이 해결해야 할 ‘이빨 빠진 연결’을 정의하기 위해.

입력
앞의 수요·공급·플랫폼·실패·시간·현장·행동 모든 데이터.

23. 사업기회

목적

격차 중 수요가 크고, 지불의사가 있으며, 경쟁이 과도하지 않고, 해결할 수 있고, 경제성이 있는 것만 후보로 올림.

왜

문제가 있다고 모두 사업이 아니기 때문.

입력
검증된 격차 + 수요 + 가격/예산 + 공급준비 + 해결비용 + 단위경제 + 규제 + 인과효과 + 불확실성.

24. 전체 통합계층

목적

수요·공급·플랫폼·돈·시간·실패·현장·실험을 하나의 출처추적 가능한 지식연결망으로 통합.

왜

부분 최적화가 아니라 산업 전체의 변화전파를 보기 위해.

출력
설명 가능한 기회객체, 시나리오, 개입후보, 근거경로.

25. 경험적 최종공식

목적

실제 시범사업과 행동·거래 결과가 쌓인 후 변수의 실제 영향과 가중치를 학습.

왜

사람이 임의로 정한 점수보다 현실에서 반복 검증된 예측모형을 만들기 위해.

원칙
현재 공식과 가중치는 확정하지 않음. 시간누출을 막은 학습·검증·시험자료와 실제 결과가 확보된 뒤에만 동결.

5. 25개 축을 가로지르는 8개 교차계층

① 목적지 후보·선택

한국을 안다 → 후보에 넣는다 → 다른 나라와 비교한다 → 선택/탈락한다를 분리. 일본에 갔다고 자동으로 한국의 손실수요로 계산하지 않음.

소스: 잠재 방한조사, 목적지선택 연구, 경쟁국 자료, 향후 개인 선택이력.

② 동행집단 의사결정

여행자·기획자·검색자·영향자·최종결정자·예약자·결제자·자녀·동행자가 다를 수 있음.

소스: 공식 동행유형, 가족/집단 의사결정 연구, 향후 구성원별 면담·행동자료.

③ 예산·지불의사·가격반응

실제 지출 ≠ 여행 전 예산 ≠ 최대 지불의사. 가격이 오를 때 목적지·숙박·기간·활동을 함께 바꿀 수 있음.

소스: 지출조사, 잠재여행자 조사, 선택실험 연구, 실제 노출·거절가격·할인자료.

④ 수용량·재고·시간

등록공급 ≠ 영업중 ≠ 일정존재 ≠ 플랫폼재고 ≠ 우리 일행 사용가능 ≠ 실시간 확정가능.

소스: 공식등록, 공급자 운영·인력·언어, OTA 실시간재고, 예약시스템.

⑤ 네트워크효과·사회적확산

경험 → 리뷰·영상·추천 → 다른 사람의 인지·검색·후보편입으로 이어지는 순환을 봄.

소스: 관광데이터랩 글로벌 SNS, 플랫폼지표, 리뷰, 향후 개인노출→검색→예약 연결.

⑥ 반사실·미실현수요

한국 미선택, 경쟁국 전환, 예약포기, 무여행, 병목이 없었으면 선택했을 가능성을 구분.

소스: 후보집합, 실패여정, 경쟁국, 예산, 향후 대체행동과 자연실험.

⑦ 개입비용·인과효과

병목을 고친 뒤 실제 전환·매출·이익이 얼마나 추가됐는지와 해결비용을 함께 봄.

소스: 시범사업, 비교집단, 정책변화, 노선신설, 실험·준실험, 실제 비용.

⑧ 불확실성 분해

표본오차·측정오차·출처편향·결측·정의차이·모형차이·시간노후화·인과식별 문제를 하나의 신뢰점수로 숨기지 않음.

소스: 각 센서 방법론, 오차정보, 센서간 비교, 민감도검사.

모든 관계에는 가능한 경우 관측일, 유효기간, 월/분기/연도, 자료개정일을 붙입니다. 그래야 2020년과 2026년의 같은 숫자를 같은 환경으로 착각하지 않습니다.

11. 수학공식은 어디까지 왔나

초기에는 수요·고통·정보비대칭·고립·재가치화 등을 곱한 단일 KTOF 점수를 상상했지만, 현재는 서로 종속된 변수를 그냥 곱하면 중복계산이 생긴다는 문제를 인식했습니다. 따라서 최종 구조는 하나의 거대한 점수보다 여러 하위모형을 연결하는 방식이 더 적합합니다.
